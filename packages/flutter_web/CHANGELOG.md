# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-12-17

### Added
- Initial release of ovenplayer_flutter_web package
- Flutter Web wrapper for OvenPlayer JavaScript library
- Support for WebRTC streaming with sub-second latency
- Support for LLHLS (Low Latency HLS) streaming
- Full player control API (play, pause, stop, seek)
- Volume and mute controls
- Quality level selection
- Source switching support
- Comprehensive event handling system
- Example Flutter Web application
- Full documentation and README

### Features
- `OvenPlayerWidget` - Flutter widget for displaying the player
- `OvenPlayerController` - Controller for managing player instance
- `OvenPlayerConfig` - Configuration classes for player setup
- Event callbacks for player state changes, errors, metadata, time updates
- JavaScript interop layer for seamless integration with OvenPlayer.js
- Support for multiple video sources with automatic fallback
- WebRTC specific configuration options

### Documentation
- Comprehensive README with installation and usage instructions
- Example application demonstrating all features
- API documentation with code examples
