# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-12-17

### Added
- Initial release of OvenPlayer Flutter Web package
- Flutter widget component for OvenPlayer
- Comprehensive configuration options
- WebRTC support for sub-second latency streaming
- LL-HLS and HLS support
- MPEG-DASH support
- Controller API for playback control
- Event streams for all player events
- Quality level management
- Volume and mute controls
- Fullscreen support
- Example application with complete UI
- Comprehensive documentation
- Support for OvenMediaEngine signaling protocol

### Features
- WebRTC streaming with configurable ICE servers
- Automatic fallback between protocols
- Packet loss recovery
- Multiple quality levels support
- SEI metadata parsing
- Watermark and timecode support
- Responsive player sizing
- Cross-browser compatibility

### Documentation
- Complete README with usage examples
- API reference for all configuration options
- Example streams and setup instructions
- Troubleshooting guide
